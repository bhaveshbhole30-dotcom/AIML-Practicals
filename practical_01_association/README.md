# Practical 1: Association Between Dependent and Independent Variables

## Aim
Identify the association between independent variables and a dependent variable.

## Theory
Correlation measures the strength and direction of association between numeric variables. Pearson correlation is used here, followed by a simple regression line for visualization.

## Procedure
Load a small reproducible dataset, calculate the correlation matrix, identify the strongest association with the target, and visualize the relationship.

## Execution
```bash
python practical_01.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
