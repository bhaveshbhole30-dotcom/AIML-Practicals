# Practical 4: Naive Bayes Classification

## Aim
Apply a Naive Bayes classification algorithm.

## Theory
Naive Bayes applies Bayes' theorem with a conditional independence assumption among features. Gaussian Naive Bayes is suitable for continuous numeric features.

## Procedure
Use the Iris dataset, split it into training and testing sets, train Gaussian Naive Bayes, predict test labels, and report accuracy and a classification report.

## Execution
```bash
python practical_04.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
