# Practical 6: Linear Regression

## Aim
Implement a Linear Regression algorithm.

## Theory
Linear regression models a continuous dependent variable as a linear combination of one or more independent variables. Model performance can be measured using MAE, MSE, RMSE and R².

## Procedure
Create a reproducible housing-style regression dataset, split it, train Linear Regression, calculate evaluation metrics, and plot actual versus predicted values.

## Execution
```bash
python practical_06.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
