# Practical 9: Object Detection from CCTV Footage

## Aim
Apply object detection to CCTV/video footage.

## Theory
Object detection identifies objects and draws bounding boxes with class labels and confidence scores. This practical uses a pretrained YOLO model through the Ultralytics library.

## Procedure
Place a video named input.mp4 in data/, run the program, and inspect the annotated output video in outputs/. A webcam can also be used by changing the source.

## Execution
```bash
python practical_09.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
