# Practical 3: Dimensionality Reduction Using PCA

## Aim
Reduce the dimensionality of a dataset using Principal Component Analysis.

## Theory
PCA transforms correlated variables into orthogonal principal components ordered by explained variance. It is useful for visualization and reducing feature dimensions.

## Procedure
Standardize Iris features, fit PCA with two components, print explained variance, and visualize the two-dimensional representation.

## Execution
```bash
python practical_03.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
