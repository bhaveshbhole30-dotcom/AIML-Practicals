# Practical 5: KNN Classification

## Aim
Apply the K-Nearest Neighbors algorithm for classification.

## Theory
KNN classifies a sample according to the majority class among its nearest neighbors. Feature scaling is important because distance is used.

## Procedure
Standardize Iris features, split the data, train KNN with K=5, evaluate accuracy, and show the confusion matrix.

## Execution
```bash
python practical_05.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
