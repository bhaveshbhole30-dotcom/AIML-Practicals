# Practical 7: SVM for Regression

## Aim
Implement Support Vector Machine regression.

## Theory
Support Vector Regression (SVR) uses a margin/tolerance tube around the regression function. Scaling is essential for RBF SVR.

## Procedure
Generate a nonlinear regression dataset, split it, scale features, train RBF SVR, evaluate it, and plot predictions.

## Execution
```bash
python practical_07.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
