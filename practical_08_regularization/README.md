# Practical 8: Regularization to Avoid Overfitting

## Aim
Apply regularization to reduce overfitting in regression.

## Theory
Ridge adds an L2 penalty and Lasso adds an L1 penalty to the loss function. Regularization discourages overly large coefficients and can improve generalization.

## Procedure
Create a high-degree polynomial regression problem, compare unregularized Linear Regression with Ridge and Lasso, and compare test MSE.

## Execution
```bash
python practical_08.py
```

## Result
The program prints the evaluation/result and saves generated figures in the `outputs` folder.
